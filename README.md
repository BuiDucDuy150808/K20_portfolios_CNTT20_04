# Website Portfolio Cá Nhân - Bùi Đức Duy (Bản luyện tập)
## Sản phẩm này là gì?
Website giới thiệu bản thân và các dự án học tập, dành cho giảng viên và nhà tuyển dụng thực tập.
## Demo
https://buiducduy150808.github.io/K20_portfolios_CNTT20_04/
## Tính năng
Bấm vào các mục trên thanh menu để xem thông tin giới thiệu, kỹ năng và kết quả bài tập.
## Cách mở
1. Mở URL ở mục Demo bằng trình duyệt web.
2. Bấm vào từng mục trên thanh menu ở đầu trang để chuyển đến phần nội dung tương ứng.
